# X API Endpoint Map

Use this map for script-to-endpoint traceability.

- Search posts: `posts.search_recent` and `posts.search_all`
- Bookmarks: `users.get_bookmarks`
- Filtered stream rules: `stream.get_rules` and `stream.update_rules`
- Filtered stream posts: `stream.posts`
- User timeline posts: `users.get_posts`
- Post lookup: `posts.get_by_id` and `posts.get_by_ids`
- List timeline posts: `lists.get_posts`
- News lookup: `news.search` and `news.get`

Primary docs:

- `https://docs.x.com/x-api/introduction`
- `https://docs.x.com/xdks/python/overview`
